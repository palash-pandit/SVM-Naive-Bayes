# Machine Learning Practical Programs – SVM and Naïve Bayes

## 📌 Project Description
This project contains 18 Python programs based on Machine Learning algorithms, especially Support Vector Machine (SVM) and Naïve Bayes.

These programs demonstrate model training, prediction, performance evaluation, feature scaling, hyperparameter tuning, and data visualization.

## 🎯 Objectives
- Understand SVM and Naïve Bayes algorithms.
- Train and test machine learning models.
- Learn feature scaling and feature selection.
- Evaluate model performance using different metrics.
- Visualize results using Python libraries.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## 📚 List of Practical Programs

1. Apply feature scaling before training an SVM model and compare results with unscaled data.
2. Train a Gaussian Naïve Bayes classifier with and without smoothing.
3. Perform hyperparameter tuning for an SVM classifier using GridSearchCV.
4. Train an SVM classifier on an imbalanced dataset and compare class weighting.
5. Perform spam detection using a Naïve Bayes classifier.
6. Compare the accuracy of SVM and Naïve Bayes classifiers.
7. Apply feature selection using SelectKBest before training a Naïve Bayes classifier.
8. Compare One-vs-Rest and One-vs-One strategies in SVM.
9. Compare different SVM kernels: Linear, Polynomial, and RBF.
10. Evaluate an SVM classifier using Stratified K-Fold Cross-Validation.
11. Train a Gaussian Naïve Bayes classifier using different class priors.
12. Perform feature selection using Recursive Feature Elimination (RFE) with SVM.
13. Train an SVM classifier and evaluate it using Precision, Recall, and F1-Score.
14. Train a Naïve Bayes classifier and evaluate it using Log Loss.
15. Train an SVM classifier and visualize the Confusion Matrix using Seaborn.
16. Train an SVM Regressor (SVR) and evaluate it using Mean Absolute Error (MAE).
17. Train a Naïve Bayes classifier and evaluate it using ROC-AUC Score.
18. Train an SVM classifier and visualize the Precision-Recall Curve.
